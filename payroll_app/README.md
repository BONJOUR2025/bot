# Payroll App (MVP)

Локальное веб‑приложение на FastAPI для расчёта зарплаты администраторов по данным:
- Excel: "ФОТ админы 2026.xlsx" (оклад AU3:AU21, имена A3:A21 на листе месяца)
- Firebird (.fdb): продажи по 3 категориям (ремонт/химчистка, косметика, обувь)
- JSON: advance_requests.json (авансы), bonuses_penalties.json (премии/удержания)
- SQLite: планы продаж по категориям (ручной ввод через веб‑страницу)

## Установка
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка путей
Откройте `settings.py` и укажите реальные пути к файлам/базе и (если нужно) логин/пароль Firebird.

## Запуск
```bash
uvicorn main:app --reload
```

Откройте:
- http://127.0.0.1:8000/payroll?year=2026&month=2
- http://127.0.0.1:8000/plans?year=2026&month=2

## Примечания
- По умолчанию ставка % берётся по нижнему уровню, если план = 0 (чтобы не завышать).
- Сотрудник определяется по последним 4 цифрам в имени/description.
