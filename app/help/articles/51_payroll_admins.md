Расчёт зарплаты администраторов салонов за месяц: оклад по сменам, комиссия с продаж по категориям, премии, штрафы, авансы и сумма к выплате.

## Как посчитать зарплату за месяц
**Где:** Меню → Зарплата → Администраторы
1. Выберите месяц вверху страницы.
2. Найдите сотрудника через «Поиск по ФИО…» или пролистайте список.
3. В карточке видно: оклад (основная ставка за 1–15 смен, доп. ставка с 16-й смены), смены по точкам, продажи по категориям (ремонт/химчистка, косметика, обувь), план, % выполнения, ставку комиссии, премии, авансы, штрафы и «К выплате».

## Как работает комиссия
- Ремонт/химчистка: ≥80% плана → 2%, иначе 1%.
- Косметика: ≥80% плана → 8%, иначе 5%.
- Обувь: ≥80% плана → 5%, иначе 3%.
План сотрудника рассчитывается автоматически из планов точек и смен (см. «Планы продаж»).

## Как задать сотруднику свой план
**Где:** Меню → Зарплата → Администраторы → карточка сотрудника → кнопка «Настроить план»
В карточке сотрудника нажмите «Настроить план». Можно задать планы по ремонту, косметике и обуви, отметить «Не учитывать KPI», «Свести в максимум» (комиссия всегда по максимальной ставке) или «Свести в минимум». Сохраните. Ручной план важнее автоматического.

## Как отметить, что расчёт выдан
**Где:** Меню → Зарплата → Администраторы → карточка сотрудника → кнопка «Отметить как выданный»
Нажмите кнопку «Отметить как выданный» в карточке сотрудника. Повторное нажатие («Расчёт выдан — нажмите для отмены») снимает отметку. Сколько расчётов выдано — видно в итогах сверху.

## Комментарий к выплате
**Где:** Меню → Зарплата → Администраторы → карточка сотрудника → кнопка «Комментарий»
Кнопка «Комментарий» в карточке — заметка к выплате этого месяца, «Сохранить».

## Журнал изменений
**Где:** Меню → Зарплата → Администраторы → кнопка «Журнал» вверху
Кнопка «Журнал» показывает, кто и когда менял планы и отметки выдачи в выбранном месяце.

Если вверху предупреждение «Неизвестные коды точек в расписании» — в графике есть коды, для которых нет плана; добавьте их в «Планы продаж» (и код салону в «Салоны»).
