Проводки кассовой книги Агбиса: приход, расход, инкассация по филиалам. Здесь им назначают категории и связывают с выплатами сотрудникам.

## Вкладки
- **Обзор** — общая сумма, сколько записей с выплатой и без, динамика, суммы по категориям.
- **Движения** — таблица проводок.
- **Аналитика** — разбивка по категориям, филиалам, дням недели.
- **Остатки** — остатки по кассам на текущий момент и движение за период (на начало, приход, расход, инкассация, на конец).

## Как найти проводки
**Где:** Меню → Деньги → Кассовые перемещения → вкладка «Движения»
Задайте «Дата с / Дата по» (или «Этот месяц», «Прошлый месяц», «Этот год», «Всё время»), фильтр по филиалу, «Поиск по Основанию…» (режим «И» — все слова, «ИЛИ» — хотя бы одно), «Только без категории», «Только без выплаты». Колонки сортируются нажатием на заголовок.

## Как назначить категорию
**Где:** Меню → Деньги → Кассовые перемещения → вкладка «Движения»
- Вручную: в строке нажмите «Назначить», выберите категорию.
- Правилом: при назначении включите «Создать правило (добавить префикс)» — все записи, у которых «Основание» начинается так же, будут автоматически попадать в эту категорию.
- «Очередь без категории» / «Показать записи без категории» — быстро разобрать неразмеченное.
Категории и их префиксы редактируются в «Управление категориями».

## Как связать проводку с выплатой
**Где:** Меню → Деньги → Кассовые перемещения → вкладка «Движения»
В строке нажмите «Привязать выплату»: «Привязать существующую» (выберите выплату за период) или «Создать новую» (сотрудник, тип выплаты — аванс, зарплата, премия, другое) — выплата появится в разделе «Выплаты» уже привязанной.

## Филиалы
**Где:** Меню → Деньги → Кассовые перемещения → кнопка «Филиалы» вверху
«Филиалы (ID → название)» — соответствие ID из Агбиса и названий. При добавлении нового филиала или пользователя в Агбис добавьте его ID и имя здесь.
