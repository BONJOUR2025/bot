Месячные планы продаж по точкам и планы менеджеров по работе с клиентами.

## Как выставить план точкам
1. Выберите месяц вверху страницы.
2. На вкладке «Точки» для каждой точки заполните три суммы: «Ремонт / Химчистка, ₽», «Косметика, ₽», «Обувь, ₽».
3. Нажмите «Сохранить планы».
В таблице видны только активные салоны с кодом точки. Если точки нет — задайте ей код в разделе «Салоны».

## Как считается личный план администратора
- Дневной план точки = месячный план точки ÷ количество дней в месяце.
- Индивидуальный план = сумма (дневной план точки × смены сотрудника на этой точке по графику).
- Если сотруднику задан ручной план в «Расчёте зарплаты» (кнопка «Настроить план»), он имеет приоритет.

## Планы менеджеров
На вкладке «Менеджеры» для каждого сотрудника с должностью «менеджер по работе с клиентами» задайте: «Оклад, ₽», «KPI макс, ₽», «План выручки, ₽», «Конв. ремонта, %», «Конв. пошива, %» и нажмите «Сохранить планы». Эти цифры используются в разделе «Менеджеры» (зарплата).
