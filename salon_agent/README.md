# Салонный аудио-агент

Стримит звук микрофона салонного ПК в админ-панель по требованию (пока кто-то
слушает). Живое прослушивание, ничего не пишется. Часть системы аудиоконтроля
рабочих процессов — разворачивать **только** при выполненном организационном
основании (см. ниже).

## Правовое основание — до запуска, вне кода

Модель — открытый аудиоконтроль по **ст. 214.2 и 86 ТК РФ**. До боевого пуска:

- ЛНА работодателя об аудиоконтроле: основание, **цель**, объём, порядок,
  круг лиц с доступом;
- работники **ознакомлены под подпись**;
- посетители уведомлены (таблички на входе/у стойки);
- для аудио с участием клиентов — основание и цель по **152-ФЗ**.

Индикатор реального времени намеренно не встроен — это решение оператора,
принятое под запись. Он снижает риск в возможном споре, но не является
условием законности при выполненном раскрытии выше.

## Что нужно на салонном ПК

- **ffmpeg** в `PATH` (`ffmpeg -version` должен отвечать).
- **Python 3.11** и пакет: `pip install websockets`.

## Настройка

1. Узнать точное имя микрофона:
   ```
   ffmpeg -list_devices true -f dshow -i dummy
   ```
   Взять строку из раздела *DirectShow audio devices*, например
   `Microphone (USB Audio Device)`.
2. Скопировать `config.example.json` → `config.json`, заполнить:
   - `salon_id` — id салона (как в системе, напр. `8`);
   - `token` — длинный случайный секрет **этого** салона; тот же токен
     прописать на сервере в `config.json` → `salon_audio_tokens` (см. ниже);
   - `mic_device` — имя из шага 1.
3. Проверка вручную:
   ```
   python agent.py
   ```
   Должно написать «подключён к серверу как салон …». Пока никто не слушает —
   ffmpeg не запускается (это правильно).

## Токены на сервере

В боевом `config.json` (в Desktop-каталоге, НЕ в репозитории):

```json
"salon_audio_tokens": {
  "8":  "тот-же-секрет-что-в-агенте-салона-8",
  "11": "секрет-салона-11"
}
```

Секреты живут только здесь и в конфиге агента — в репозиторий не коммитятся.

## Автозапуск как служба

Через NSSM (проще всего на Windows):

```
nssm install bonjour-salon-audio "C:\Python311\python.exe" "C:\salon_agent\agent.py"
nssm set bonjour-salon-audio AppDirectory "C:\salon_agent"
nssm start bonjour-salon-audio
```

Либо через уже стоящий на машине pm2:

```
pm2 start python --name salon-audio -- C:\salon_agent\agent.py
pm2 save
```

Агент сам переподключается при обрыве сети (экспоненциальная пауза до 30 с),
поэтому перезапуск службы нужен только при обновлении кода.

## Доступ к прослушиванию

В админ-панели кнопка «слушать» доступна под правом **`salon-audio`**.
Каждая сессия прослушивания пишется в `audio_listen_log.json` на сервере:
кто, какой салон, когда начал/закончил и сколько слушал.
