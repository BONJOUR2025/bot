# Подробная инструкция: создание вакансии и работа с новым интерфейсом найма

## Что изменилось и зачем

Раньше у каждой вакансии было одно текстовое поле «база знаний» плюс одно общее
поле для всех вакансий, и ИИ просто склеивал их в один текст. Из-за этого был
риск, что админ случайно впишет данные конкретной вакансии в общее поле — и
тогда ИИ-ассистент мог рассказать кандидату на одну вакансию подробности
другой. Это исправлено:

- Теперь каждая запись базы знаний явно привязана либо к **конкретной
  вакансии**, либо помечена как **общая для всех вакансий** — перепутать
  невозможно, везде стоит цветной значок: 🌐 (общее) или 📌 (только эта
  вакансия).
- Любой текст, который увидит ИИ (ответы в базе знаний, особые инструкции),
  **нельзя сохранить без предварительной проверки через ИИ**. Кнопка
  «Сохранить» заблокирована, пока вы не нажмёте «Проверить через ИИ» — и если
  после проверки вы поменяете хоть одну букву, проверку нужно делать заново.
  Это работает и на сервере: даже если как-то обойти интерфейс, сервер вернёт
  ошибку и не даст сохранить непроверенный текст.
- Автоматизация (фильтры, авто-сообщения) и follow-up-напоминания теперь
  настраиваются не одним общим переключателем на все вакансии, а через
  **«Стратегии найма»** — именованные наборы настроек, которые назначаются
  каждой вакансии отдельно и можно менять в любой момент.
- **Follow-up-напоминания и автоматизация по умолчанию выключены** — после
  обновления везде стоит «выкл.», независимо от того, что было настроено
  раньше. Включать нужно осознанно, для конкретной стратегии.
- Авто-отказ кандидату **никогда не происходит сам**. Если кандидат долго не
  отвечает на напоминания, система только показывает админу предупреждение в
  карточке кандидата с кнопками «Отказать» / «Подождать ещё» — решение всегда
  за человеком.

## Шаг 1. Создание вакансии

1. Откройте раздел **«Подбор персонала»** в боковом меню.
2. В правом верхнем углу нажмите **«Новая вакансия»**.
3. Откроется мастер создания вакансии из 5 шагов: **Основное → Стратегия
   найма → Вопросы кандидатов → Особые инструкции → Готовность**. Шаги
   показаны вкладками сверху, между ними можно переключаться после того, как
   вакансия будет сохранена хотя бы на первом шаге.

### Шаг 1.1 — «Основное»

- **Название*** — обязательно, например «Мастер по ремонту обуви».
- **Описание** — необязательно, краткое описание вакансии.
- **Место собеседований** — адрес или ссылка на онлайн-встречу; эту фразу ИИ
  будет называть кандидату, если спросят «где собеседование».
- **Устаревшая база знаний (миграция)** — это старое текстовое поле, оставлено
  только для совместимости со старыми вакансиями. **Не используйте его для
  новых вакансий** — вместо этого заполняйте базу знаний на шаге 3, там каждый
  ответ привязывается к вакансии надёжно через структурированную запись, а не
  через один большой кусок текста.
- Нажмите **«Далее»** — вакансия будет сохранена, и откроется шаг 2.

### Шаг 1.2 — «Стратегия найма»

Здесь вы выбираете, какой набор настроек автоматизации будет работать для этой
вакансии. Есть 4 готовые («встроенные») стратегии:

- **Стандартный отбор** — без агрессивной автоматизации.
- **Быстрый найм** — короче сроки реакции.
- **Точный подбор** — более узкие фильтры по кандидатам.
- **Массовый набор** — для вакансий с большим потоком кандидатов.

У каждой стратегии в карточке справа видно:
- включены ли напоминания (follow-up) и через сколько часов;
- через сколько часов система предложит админу отказать неотвечающему
  кандидату (или «никогда», если это не настроено);
- какая модель ИИ используется (если задана отдельно).

**По умолчанию во всех стратегиях напоминания выключены** — это сделано
специально, чтобы автоматика не начала писать кандидатам без вашего явного
решения.

Если ни одна из готовых стратегий не подходит — нажмите **«Управление
стратегиями»**, там можно создать свою с нужными фильтрами по возрасту,
источникам, текстами сообщений для hh.ru, текстом автоответа в нерабочее время
и т.д. Стратегию для вакансии можно поменять в любой момент — просто
вернитесь на этот шаг.

### Шаг 1.3 — «Вопросы кандидатов»

Это самое важное новое место. Как только вакансия сохранена (название
указано), ИИ автоматически придумывает список вероятных вопросов, которые
кандидаты могут задать именно по этой вакансии (про график, зарплату,
требования, условия и т.д.), и группирует их по категориям.

Что делать:
1. Под каждым предложенным вопросом — поле для ответа. Напишите ответ.
2. Нажмите **«Проверить через ИИ»** — система покажет краткое резюме того, что
   вы написали, и предупредит, если текст выглядит так, будто он не про эту
   вакансию (например, вы случайно вставили текст другой вакансии).
3. Если всё в порядке — справа появится «Проверено, можно сохранить», и кнопка
   **«Подтвердить и сохранить»** станет активной. Нажмите её — ответ
   сохранится именно для этой вакансии (значок 📌 рядом подтверждает scope).
4. Если вы передумаете и поменяете текст ответа уже после проверки — индикатор
   «Проверено» исчезнет, и придётся проверить заново перед сохранением. Это
   защита от случайного сохранения непроверенного текста.
5. Внизу есть кнопка **«Добавить свой вопрос»** — если кандидаты обычно
   спрашивают что-то, чего ИИ не предположил.
6. Кнопка **«Открыть базу знаний вакансии»** открывает полный список всех
   сохранённых вопросов-ответов этой вакансии — там можно их редактировать или
   удалять.

### Шаг 1.4 — «Особые инструкции»

Поле для коротких, наивысшего приоритета указаний именно по этой вакансии,
например: «никогда не называть точную дату выхода, только „после
собеседования“». Эти инструкции учитываются даже если они противоречат базе
знаний. Работает по тому же принципу: написали текст → «Проверить через ИИ» →
если всё ок, кнопка подтверждения активна → «Подтвердить и сохранить
инструкции».

### Шаг 1.5 — «Готовность»

Чек-лист того, что нужно для полноценной работы ИИ-ассистента по вакансии:
- настроен ли API-ключ ИИ (общий, в Настройках);
- есть ли хотя бы одна запись в базе знаний;
- указано ли место собеседований;
- выбрана ли стратегия найма.

Если что-то не готово — вверху будет жёлтое предупреждение, но это **не
блокирует** сохранение вакансии — просто напоминание, что стоит дозаполнить.

Когда всё устроит — нажмите **«Готово»**.

## Шаг 2. Общая база знаний (для всех вакансий сразу)

Если есть информация, которая верна для **любой** вакансии в компании
(например, «мы оплачиваем проезд», «офис работает с 9 до 19»), не вписывайте
её в базу знаний конкретной вакансии — используйте общую:

1. В разделе «Подбор персонала» нажмите кнопку **«Общая база знаний»** в
   шапке страницы.
2. Откроется тот же интерфейс, что и для вакансии, но с синим значком 🌐
   «Общее — для всех вакансий» — чтобы не перепутать с вакансийной базой.
3. Добавление работает по тому же принципу: вопрос, ответ, «Проверить через
   ИИ», затем «Подтвердить и сохранить».

**Важно:** не добавляйте сюда детали конкретной вакансии (зарплату, график
именно одной точки и т.п.) — иначе эта информация попадёт в ответы ИИ по всем
вакансиям без разбора.

## Шаг 3. Управление стратегиями отдельно от вакансии

Кнопка **«Стратегии найма»** в шапке страницы «Подбор персонала» открывает
список всех стратегий (встроенных и созданных вами) без необходимости
заходить в конкретную вакансию. Здесь можно:
- создать новую стратегию;
- отредактировать существующую (кроме встроенных — их можно только
  использовать, не редактировать/удалять);
- удалить свою стратегию, если её не использует ни одна вакансия.

---

## Шаг 4. Что происходит, если кандидат долго не отвечает

Если для вакансии в стратегии настроены follow-up-напоминания и срок
авто-отказа (`decline_after_hours`), и кандидат не ответил после всех
напоминаний — система **не отказывает кандидату сама**. Вместо этого:

1. В карточке кандидата появляется красная плашка: «Кандидат долго не отвечает
   на напоминания. Система предлагает отказать — решение за вами.»
2. У вас два варианта:
   - **«Отказать»** — кандидат переводится на этап отказа.
   - **«Подождать ещё»** — предупреждение скрывается, кандидат остаётся на
     своём этапе, через какое-то время предупреждение может появиться снова.

---

## Шаг 5. Глобальные настройки автоматизации (раздел «Настройки» → «Автоматизация»)

Старые общие настройки фильтров и follow-up в разделе «Настройки» теперь
работают **только как запасной вариант** для вакансий, у которых стратегия
**не выбрана**. Как только вакансии назначена стратегия — все её настройки
автоматизации, follow-up и шаблонов сообщений берутся из стратегии, а
настройки в «Настройках» на неё больше не влияют. Это явно написано жёлтым
предупреждением прямо в интерфейсе настроек.

## Краткая памятка (если забудете детали)

| Что делаете | Где | Что нужно помнить |
|---|---|---|
| Информация только про одну вакансию | Шаг 3 мастера вакансии («Вопросы кандидатов») или «Открыть базу знаний вакансии» | Значок 📌, видно только этой вакансии |
| Информация для всех вакансий | Кнопка «Общая база знаний» в шапке | Значок 🌐, видно всем вакансиям — не пишите туда детали одной вакансии |
| Любой текст для ИИ | Везде | Нельзя сохранить без «Проверить через ИИ» сразу перед сохранением |
| Включить напоминания/авто-сообщения | Стратегия найма, назначенная вакансии | По умолчанию выключено — включайте осознанно |
| Кандидат долго молчит | Карточка кандидата | Решение об отказе принимает только админ, никогда не автоматика |
