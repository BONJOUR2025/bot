# BONJOUR Салон

Приложение для телефонов администраторов точек: оболочка над кабинетом
сотрудника на app.bonjour.pw, стартует на «Зарплате» (`/employee/salary`).

Это личный кабинет с тем же набором, что кнопки бота у администратора:
зарплата, график, авансы, история выплат, имущество, профиль. Рабочих
инструментов точки (выручка, заказы клиентов) в нём нет.

Это тот же WebView-каркас, что у «BONJOUR Мастер» (device/master_app):
отличаются только имя пакета (`pw.bonjour.salon`), название, стартовый адрес
и метка в User-Agent (`BonjourSalonApp/<версия>`, по ней кабинет показывает
плашку обновления и прячет то, что во WebView не работает).

Поэтому правки каркаса — выбор фото, сканер бирок, обработка ошибок связи —
нужно вносить в оба приложения: общего модуля намеренно нет, чтобы одно
приложение нельзя было сломать правкой в другом.

## Сборка

Локально собирать нечем (нет JDK и Android SDK) — собирает GitHub Actions
(`.github/workflows/salon-app.yml`) и сам кладёт APK на сервер, откуда
администратор качает его со страницы https://app.bonjour.pw/api/salon-app/.

Подпись — тем же ключом, что у агента MDM и приложения мастера
(секреты `MDM_KEYSTORE_B64` / `MDM_KEYSTORE_PASSWORD`): обновление с другой
подписью поверх установленного приложения не встанет.

`versionCode` обязан расти с каждой выпущенной сборкой.
